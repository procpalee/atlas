# 감사 인게이지먼트 관리 툴

## 🎯 목표
- 감사 실무 프로젝트를 **폴더 = 엔게이지먼트, 하위 폴더 = 단계**(감사계획 → 중간감사 → 기말감사 → 아카이빙) 구조로 표준화하고, 그 안의 엑셀 조서·회사 수증자료(PBC)를 추적·시각화
- 기성 툴 부재(Caseware류는 무겁고 Claude 연동 불가) → 직접 구축. 기존 자산 재활용: `프로젝트 관리`의 project_board MCP 패턴, single-file HTML 보드
- [[04.1. 업무별 에이전트 구축]]의 회계감사 에이전트가 이 툴을 통해 엔게이지먼트 상태를 읽고 갱신

## 🧩 구성 요소 (안)
1. **폴더 규약**: 허브 `04. 엔게이지먼트\<회사명>\` + 단계별 하위 폴더(감사계획·중간감사·기말감사 등) — 기존 `Audit_흥구석유` 구조는 참고용이며, 실제 규약은 착수 시 구체적으로 설계 (사용자 결정)
2. **인덱스**: 폴더를 스캔해 파일 메타데이터(단계, 계정, 상태, 수증일)를 JSON/엑셀로 관리 — PBC 요청 리스트와 수증 현황 대조
3. **대시보드**: single-file HTML — 단계별 칸반, 조서 진행률, PBC 미수증 알림
4. **MCP/스킬 연동**: Claude가 인덱스를 읽고 갱신 (조서 작성 완료 시 상태 자동 변경, 누락 PBC 질의 생성)
